# CT Volume Viewer

CT データ (DICOM / NIfTI) や 3次元 NumPy 配列を GPU ボリュームレンダリングで表示するシンプルなデスクトップビューワ。

## インストール

```
pip install -r requirements.txt
```

## 起動

```
python app.py
```

## 使い方

1. 左上のボタンからデータを開く (.npy / DICOM フォルダ / .nii・.nii.gz)
2. マウスでドラッグ回転、ホイールでズーム
3. **ウインドウ処理**: WL (レベル)・WW (幅) スライダーをドラッグするとリアルタイムに反映
   - 伝達関数のみ更新するため GPU への再アップロードが無く高速
   - CT (HU 値) なら「骨 / 肺 / 軟部」プリセットボタンが使える
4. **等値面モード**: ラジオボタンで切替。しきい値スライダーで表面抽出 (PBR シェーディング)

## 備考

- .npy は (z, y, x) の 3次元配列とみなす (ボクセル間隔は等方 1.0)
- DICOM は RescaleSlope/Intercept を適用して HU 値に変換、スライス位置でソート
- 大きなボリューム (512³ 以上) は GPU メモリ次第で重くなることがある
